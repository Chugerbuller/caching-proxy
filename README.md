# Go Caching Reverse Proxy

Легковесный кэширующий прокси-сервер на Go, который оптимизирует нагрузку на внешние API, кэшируя GET-запросы в Redis.

Интересен тем, что под капотом решены классические проблемы кастомных прокси: перехват стрима ответов для сохранения в Redis в обход ограничений HTTP-протокола и аккуратная трансляция оригинальных заголовков без блокировок со стороны систем защиты (Cloudflare/Heroku).

---

## Архитектура и ключевые фичи

### 1. Как устроен кэш (Паттерн Decorator)

Стандартный http.ResponseWriter в Go работает как труба — данные улетают в сокет сразу при вызове Write(), и прочитать их обратно после отправки клиенту невозможно.

Для обхода этого ограничения написан кастомный responseBodyWriter:

* Он встраивается в контекст Gin.
* Перехватывает поток байт и дублирует его в bytes.Buffer в оперативной памяти.
* На обратном пути из Middleware (c.Next()) кэш-движок забирает сохраненный ответ из буфера и отправляет его в Redis.

### 2. Метрики работы сервера

Сервер имеет встроенную ручку диагностики:

* GET /stats — показывает количество попаданий в кэш (HIT), промахов (MISS), размер кэша в Redis и время последней очистки.
* POST /clear — ручной сброс всего кэша.
---

## Стек технологий

* Язык: Go (1.24)
* Веб-фреймворк: Gin gonic
* База данных кэша: Redis (go-redis/v9)
* Конфигурация: YAML (cleanenv)
* Контейнеризация: Docker + Docker Compose

## Быстрый старт

### Настройка конфигурации

Все настройки лежат в файле config.yaml в корне проекта:

```yaml
server:
  port: ":8080"
  upstream_url: "[https://jsonplaceholder.typicode.com](https://jsonplaceholder.typicode.com)"
  cache_ttl: "1m"

redis:
  addr: "localhost:6379"
  password: ""
  db: 0
  # Сборка и запуск приложения
```
```bash
docker compose up --build
```

## Как тестировать

Для проверки кэша обязательно используйте честные GET запросы. Используйте строчную -i для вывода заголовков вместе с телом ответа:

### Шаг 1: Первый запрос (Cache Miss)

```bash
curl -i http://localhost:8080/posts/1
```
### Шаг 2: Повторный запрос (Cache Hit)

```bash
curl -i http://localhost:8080/posts/1
```
```http
X-Cache: HIT
```
### Шаг 3: Просмотр статистики
```bash
curl http://localhost:8080/stats
```
```json
{
  "hits": 1,
  "misses": 1,
  "evictions": 0,
  "last_cleared": "2026-06-19T11:00:00Z",
  "size": 1
}
```
